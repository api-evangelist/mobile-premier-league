# Mobile Premier League

> Mobile Premier League (MPL) is a mobile skill-gaming and esports platform founded in 2018 in
> Bengaluru, India, operated by Galactus Funware Technology. It distributes casual, card, board
> and fantasy-sports titles inside a single app and runs tournaments around them. MPL publishes
> no public API today.

Generated by API Evangelist on 2026-08-25 from this repository. This is a third-party profile;
MPL does not serve an llms.txt of its own (probed 2026-08-25: 404 on www.mplgames.com/llms.txt,
www.mpl.live/llms.txt and api.mpl.live/llms.txt).

## API surface

There is no publicly documented Mobile Premier League API. Contract discovery on 2026-08-25 probed
every known host — api.mpl.live, www.mpl.live, www.mplgames.com — for /openapi.json,
/openapi.yaml, /swagger.json, /v1/openapi.json, /api-docs, /docs, /redoc, /graphql, /llms.txt and
the full /.well-known/ set. Every path returned 404. No OpenAPI, no GraphQL SDL, no AsyncAPI, no
MCP server, no A2A agent card, no gRPC or WSDL contract, no first-party SDK on npm, PyPI or any
other registry.

MPL formerly ran a game-developer program — a Developer Dashboard at developer.mpl.live and a
publish-and-monetize SDK documented at docs.developer.mpl.live — for studios shipping games onto
the MPL platform under revenue share. Both hosts are gone: docs.developer.mpl.live is NXDOMAIN,
and developer.mpl.live is a dangling CNAME to a deleted AWS load balancer.

## Company

- [MPL Games](https://www.mplgames.com/): the live consumer surface, principally serving the US.
- [About MPL](https://www.mplgames.com/about-us): 30+ games, 100M+ registered users.
- [MPL India](https://www.mpl.live/): legacy India surface; real-money gaming discontinued in
  2025 under the Promotion and Regulation of Online Gaming Act, 2025.
